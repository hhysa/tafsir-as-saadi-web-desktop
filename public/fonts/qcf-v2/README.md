# King Fahd Complex V2 / Madinah Mushaf

604 unmodified QCF2 page fonts extracted from the King Fahd Complex Al-Madinah Mushaf Windows v2.1 distribution, obtained from this mirror:
https://github.com/manaf/KFGQPC-Madinah-Mushaf
Archive: https://media.githubusercontent.com/media/manaf/KFGQPC-Madinah-Mushaf/main/Al_Madinah_Mushaf_Win_Setup-2.1.zip

Publisher: King Fahd Glorious Quran Printing Complex (https://qurancomplex.gov.sa/).
Glyph mappings: Quran.com API v4, words.code_v2 and words.page_number, mushaf=1.
Retrieved 2026-09-29. SHA256.json records the checksum of every font.
The existing Unicode Hafs font remains available for verse numbers and fallback; Arabic search and accessibility use the original Unicode text.

The archive was only opened to extract fonts; its installer was not executed.
